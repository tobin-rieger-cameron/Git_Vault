# 1.1 Polynomial Review

Consider the following polynomial: 3x²y³ - 9x³ + 5 -> algebraic expression & Polynomial

For the term 3x²:
  3 : Coefficient
  x : Variable
  ² : Exponent

## What makes this a polynomial?

> [!hint] hint
> if you change the exponents to negative or
> decimal numbers, the term is no longer a Polynomial

To make a polynomial, the exponents have to be natural numbers
  a whole number in an integer
  a positive integer is a natural number

$3x²y³$           : a term, it is also a monomial
$3x²y³ - 9x³$     : a binomial
$3x²y³ - 9x³ + 5$ : a trinomial

The degree comes from the sum of the exponents of the variables, so:
  3x²y³ has a degree of 5

We specify exponents because there is a hidden 3¹ beside every integer.
The degree of 5 is 0. Because every integer has a hidden x⁰

To get the degree of an entire polynomial, we take the highest degree of
its terms, so the degree of: $3x²y³ - 9x³ + 5$ is 5.

## Performing Operations on Polynomials

ex. simplify <- make it look easier

  Combine like terms (variables) with the same exponents

  1. $5x + 3x = 8x$ ← Just add the coefficients

  2. $3x²y - 5xy² + 7xy² - 12yx²$
    $= -9x²y - 2xy²$

  3. $(a-2b)-(3a-b)$
    $= 1(a-2b)-1(3a-b)$
    $= a-2b-3a+b$
    $= -2a-b$

  Work with coefficients and variables separately
  4. $6x(4x²)$
    $= (6)(4)(x¹)(x²)$ ← add exponents when multiplying
    $= 24x³$

  5. $12xy²(3x²y³-4xy²)$
    $= 36x³y⁵-48x²y⁴$
