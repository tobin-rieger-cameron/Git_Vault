# Faceted Classification

Faceted classification is a type of classification system that organises objects or concepts into categories based on multiple independent attributes — called **facets** — rather than a single hierarchical dimension.

## How It Works

Each item can be described by a combination of facets simultaneously. Common facets include:

- **Subject matter** — what the item is about
- **Form/format** — the physical or digital type (book, article, dataset)
- **Geographic location** — where it applies
- **Time period** — when it was produced or applies to
- **Language** — the language of the content

Items are not forced into a single category. Instead, a user can navigate from any facet direction and still reach the same item.

## Ranganathan and the Colon Classification

The foundational theory of faceted classification was developed by S.R. Ranganathan in the 1930s. His **Colon Classification** system defines five universal facets, known as **PMEST**:

| Facet | Meaning | Example |
|---|---|---|
| Personality | The primary subject | Agriculture |
| Matter | The material or substance | Soil |
| Energy | The process or activity | Irrigation |
| Space | Geographic focus | India |
| Time | Period | 20th century |

A work combining these gets a compound call number rather than a single linear class.

## Difference from Hierarchical Taxonomy

| Feature | Hierarchical Taxonomy | Faceted Classification |
|---|---|---|
| Structure | Tree / linear | Network / multi-dimensional |
| A concept belongs to | One parent | Multiple facet values |
| Navigation | Top-down, single path | Any facet entry point |
| Flexibility | Lower | Higher |

Hierarchical systems like the Dewey Decimal System and Library of Congress Classification are primarily hierarchical — they are *not* faceted, though they sometimes borrow facet-like notation for geographic and period subdivisions.

## Where Faceted Classification Is Used

- **Ranganathan's Colon Classification** — canonical faceted library system
- **BISAC subject codes** — publishing industry categories (multi-axis)
- **Ecommerce filtering** — product browsing by size, colour, brand, price simultaneously
- **Faceted search interfaces** — most modern search UIs expose facets as sidebar filters

## Relationship to Polyhierarchy

Faceted classification is related to but distinct from polyhierarchy. Faceted systems assign multiple attribute values from independent dimensions; polyhierarchical systems allow a single concept to have multiple *parent nodes* within one or more hierarchies.
