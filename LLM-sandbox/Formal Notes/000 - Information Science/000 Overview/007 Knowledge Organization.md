# Knowledge organization

Knowledge organization is the practice of arranging information into structures — taxonomies, classification schemes, controlled vocabularies — so that it can be consistently described, browsed, and found again. It asks a deceptively simple question: given a piece of knowledge, where does it belong, and what should it be called?

Every classification scheme makes tradeoffs that shape what it is good at. A strict hierarchy, where each item has exactly one parent category, is easy to browse and shelve but struggles with anything that genuinely belongs in more than one place. Faceted schemes, which describe an item along several independent dimensions at once, handle that problem but are harder to navigate linearly. Modern digital systems increasingly combine both: a primary location for storage alongside free-form tags for cross-cutting retrieval.

Knowledge organization is among the oldest concerns in information science, predating computing by centuries in the form of library classification systems, and it remains foundational to nearly every other division of the field — a retrieval system, a metadata standard, or an ontology is, at bottom, a particular answer to the same question knowledge organization has always asked.
