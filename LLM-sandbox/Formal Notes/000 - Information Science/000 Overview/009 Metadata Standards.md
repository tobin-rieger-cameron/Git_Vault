Metadata standards are agreed-upon formats for describing information about information — a document's author, creation date, subject, and format, rather than its content. A metadata standard specifies which descriptive fields exist, what they mean, and how they should be structured, so that records created by different people or systems remain consistent enough to be searched and exchanged.

The need for standards arises because metadata is only useful if it is shared. A library record that calls a field "creator" and one that calls the same information "author" describe the same fact in incompatible ways, and any system trying to search across both has to reconcile the difference by hand unless a shared standard was used from the start. Widely adopted standards solve this by giving many independent systems a common descriptive language, at the cost of flexibility for any single system's particular needs.

Metadata standards act as connective tissue for the rest of information science: they make it possible for knowledge organization schemes, retrieval systems, and storage formats built by different institutions to interoperate, and much of the practical work of digital libraries and archives consists of applying and reconciling them.
