/help     — list all available commands
/ingest   — rebuild the vector database from all vault markdown files
/organize — add YAML frontmatter tags and [[wikilinks]] to vault notes (two-pass LLM review)
/savefile — review and save pending LLM-generated notes to the vault
/browse   — open TUI file browser; select a file to load its content as chat context
/clear    — reset conversation history and unload any open file
/web      — toggle DuckDuckGo web search fallback on / off

Ctrl+S    — shortcut for /savefile
Ctrl+B    — shortcut for /browse
Ctrl+Q    — quit
Esc       — clear the input field
